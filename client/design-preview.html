Retrieval Pipeline

4-Stage Architecture
01

Ingest

Footage streams into a persistent frame store. Video is sampled at 1 frame per 2 seconds; static images pass through unchanged. Original files retained unmodified for evidentiary chain-of-custody.

MEDIA MP4 · MOV · JPG 13 s/img
02

Embed

Each frame is passed through a frozen SigLIP vision encoder, producing a 768-dimensional dense vector. Vectors land in LanceDB with IVF-PQ indexing for sub-linear retrieval at scale.

MODEL SigLIP-B/16-256 768-d
03

Query

Operator enters a description in natural English. The same SigLIP encoder embeds the query; the system returns the top 15 candidate frames by cosine similarity in under one second.

METRIC Cosine 0.97s med.
04

Verify

Candidate frames are passed to OWL-ViT open-vocabulary object detection using the query as the detection prompt. Frames with confirmed detections rise; false-positives fall. Bounding boxes returned with evidence.

DETECTOR OWL-ViT-B/32 geom. verified
